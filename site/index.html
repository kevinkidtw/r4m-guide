三台車一覽

車任務控制方式燒錄的程式
A 車（夾車）小雞、蜜蜂的夾取搬運KSB 搖桿 或 手機 V7RCKSB：04_KSB_車端_AB通用_v2.ts
V7RC：01_V7RC_車端_AB通用_低延遲版.ts
B 車（推扒車）用耙子與閘門推送鬱金香、牽牛花、大樹、小樹、蘑菇等物件KSB 搖桿 或 手機 V7RC和 A 車同一支程式，開機選單選「B」
KSB 遙控器給 A 或 B 車用—03_KSB發射端_搖桿_v2.ts（免設定）
C 車（循跡車）把紅、綠、藍飼料從暫放區運到對應顏色的放置區（滿分 600 分）程式自動，不能遙控R4M_C車_循跡取料_2027.ts
A 車和 B 車用同一支程式。差別只在開機選單選的車編號：A 車的 A／B 鍵控制夾爪，B 車的 A／B 鍵控制閘門、E／C 鍵控制耙子。車子端的 micro:bit 一律用 V2，KSB 遙控器用 V1 或 V2 都可以。
