A／B 車 手機 V7RC 操作

用手機藍牙控制車子，不需要配對遙控器：手機連上哪台，就只控那台。

一、第一次設定車子

  1. 按住 B 不放，同時打開車子電源。
  2. 畫面捲出字母和主控盒數字，B 繼續按著，看到 CAR 才放開。
  3. 等 CAR 捲完：夾車按 A、推扒車按 B。
  4. 等 BOX 捲完：1269 按 A、1409 按 B。
  5. 出現 ✓ 完成。

二、連線

  1. 車子開機，還沒連上手機時按 A，畫面會捲出一串英文字母（例如 zuvat），這是這台車的藍牙名稱。
  2. 把這個名稱寫在車身貼紙上。
  3. 手機打開 V7RC，選 Game ADV 介面，在裝置清單找 BBC micro:bit [zuvat] 這種名稱，點它。
  4. 車子畫面中心恆亮，就是連上了。
先連先贏：車子在還沒被連上之前，任何一支手機都連得進去（包括別隊的手機誤點）。一台車同時只能被一支手機連，所以車子開機後就馬上用自己的手機連上，連上之後別人就進不來了。

三、操作佈局（Game ADV）

手機上的位置A 車（夾車）B 車（推扒車）
左搖桿 ↕前進／後退（類比，推越多越快）同左
左搖桿 ↔轉向（大幅轉向用）同左
方向鍵 ↑ / ↓升降 上／下耙子 上／下
方向鍵 ← / →左／右微調（固定小轉速）同左
方向鍵 ↖ / ↗夾爪 張開／閉合閘門 關／開
方向鍵 ↙ / ↘沒有功能沒有功能
  • ← → 微調：每按一下轉一小段，對位置時用這個，比推搖桿準。點一下也保證轉 0.12 秒。
  • ↖ ↗ 要按斜角：手指偏了會變成升降，按準一點。同一時間只會有一個方向鍵動作成立，兩個機構不會一起亂動。
  • 機構在動或微調時，行走速度自動降到 45%，方便對位。
  • 和 KSB 搖桿版的按鍵功能、手感一致：↑↓ 對應 E／C，←→ 對應 F／D，↖↗ 對應 A／B。

四、安全設計

  • 手機斷線，或 0.3 秒沒收到訊號，車子會全停、畫面中心閃爍。
  • 手機一鎖螢幕車子就停，這是安全設計。比賽時手機螢幕保持亮著。
